# ZE1の適合資料とユニット識別の確認項目

2026-11-03。文献・既存記録のみ確認。新しい車両通信・設定変更は実施していない。

## 今回絞れた適合範囲

ユーザー申告：日本仕様ZE1 e+ G、2022年6月、車台番号の数字部分は20万番台以降。個別番号は取得していない。

[日産公式レスキュー資料一覧](https://www2.nissan-global.com/JP/SUSTAINABILITY/SOCIAL/SAFETY/RESCUE/)には「2022年6月～、ZE1-200001～」という区分がある。今回の資料選定では、この区分を確認する。これはレスキュー資料の区分であり、ADAS品番・CAN構成・診断仕様の変更を証明するものではない。購入時は販売店で個別車両への適合確認が必要。

公論出版の[ZE1整備解説書の公開サンプル](https://www.kouronpub-onlineshop.com/html/template/default/assets/pdf/howto.pdf)は2021年12月時点の4区分までを整理し、それ以降は内容が異なる可能性を明記している。この解説書だけで今回の仕様を確定しない。

## 正規資料の入手経路

[日産公式FAQ](https://faq2.nissan.co.jp/faq/show/11265?site_domain=default)は、整備要領書・配線図集・サービスマニュアルCD/DVD等を日産販売店で注文できると案内している。今回の車両用資料の在庫・媒体・価格・収録内容は未確認。購入や販売店への連絡は行っていない。

北米の[Nissan TechInfo](https://www.nissan-techinfo.com/help)にも有料のサービス資料閲覧経路があるが、日本仕様の適合資料とは限らない。今回のために北米契約を先に購入する理由は不足。

## 販売店に確認する内容

対象：日本仕様リーフZE1 e+ G、2022年6月、車台番号20万番台以降。正式な適合照会には、所有者が販売店へ個別車台番号を提示する。

1. この個別車両に適合するESM／整備要領書と配線図集の資料番号、改訂時期、購入可能な媒体・価格。
2. 収録項目にCAN／LAN構成図、ADAS・ICCのシステム構成図、ユニット位置、コネクタ配線があるか。
3. メーター裏のADASユニット、レーンカメラ、距離センサーそれぞれの名称・部品番号。装着時品番、現行補給品番、ソフトウェア識別値は区別する。
4. CONSULTのECU識別画面で、それぞれの識別情報を読み出せるか。可能なら画面名と取得項目を確認する。書換え・構成変更・DTC消去は依頼内容に含めない。
5. 整備資料に通常CAN信号の送受信ユニット表があるか。数値CAN IDの対応まで載っているかは未確認。

資料を入手してもメーカー独自の診断サービスや数値CAN IDが公開されているとは限らない。入手前に上記の収録範囲を確認する。

## 既存の識別情報が確定している範囲

手元の59/5cの記録では0x707に対する識別値は同じ24バイトで、先頭文字列は6WK6ADB。ローカルのファームウェア照会実装はKWPの21 83を使用する。ソフトウェアがこれをfwdCameraと分類していることも確認済み。

これを日産の284E7-xxxxx等の部品番号へ変換する対応表はまだ得られていない。標準UDS識別要求は既存起動ログで7F 22 11が観測されており、UDSの別識別番号を追加すれば読めるとは仮定しない。0x707と0x75Dを同一／別ユニットともまだ確定できない。

送信停止候補の追加実装はまだ行わない。まず適合するユニット構成・配線情報と、識別情報取得の根拠を揃える。資料で対象が絞れた後に、必要なら読み出しだけの診断計画を別途作る。既存の停止候補の無効化を維持する。
