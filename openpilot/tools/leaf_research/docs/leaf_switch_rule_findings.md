# 走行中の特別パターンへの移行

3 km/h以上、ペダル介入なしで始まった6区間を調べた。停止保持区間、欠損をまたぐ区間は対象外。時刻は最初のCANからの秒数。

|ルート|入口時刻|入口直前の候補値|出口直後の候補値|
|---|---:|---:|---:|
|59|423.886|5939|4186|
|59|600.416|4182|4187|
|59|670.617|4164|4185|
|59|674.086|4199|4191|
|5a|106.262|6120|4191|
|5a|274.471|4180|4185|

ルート59では入口直前値が4164～5939に分散し、直前1秒の最小値も最初の区間だけ5128と高かった。ルート5aでも最初の区間が同様に高く、直前値6120、直前1秒の最小値5325だった。瞬間的なビット飛びだけで説明するには不十分。入口を一つの通常要求値の閾値で予測する仮説は採用できなかった。初回とその後で状態や信号の意味が違う可能性が残る。

出口直後値は59で4185～4191、5aでも同じ範囲だった。ただし特別パターン中は通常値が観測できないため、この値が出口の判定原因だったとは確認できない。

6区間すべてで、入口直前の0x1C3要求値は8、出口直後は0だった。時刻の異なるCAN同士を直前値で照合した結果であり、8を入口閾値と断定するには追加の時間合わせが必要。

ルート59の観測から「0x1C3が正の間は特別パターン」とする同時刻の関連を比較した。対象はACC有効、3 km/h以上、ペダル介入なし、2B0有効、車両状態0.1秒以内、1C3直前値0.03秒以内。学習器の最適化は行っていない。

|---|---:|---:|---:|---:|---:|
|59|1369|4|19|99.71%|98.63%|
|5a|674|2|7|99.70%|98.97%|

これは出力信号同士の同時刻の関連であり、将来の切り替え予測の成績ではない。連続フレームは独立した試行でもない。通常値4200未満という分類では特別パターン自身の候補値2398を含むため、再現率100%は当然に得られ、入口予測の評価には使えない。

現段階の解釈は、特別パターンが1C3の制動要求と強く協調する状態である、というところまで。目標減速度からその状態を選ぶ条件、1C3が摩擦のみか合計要求かは未解明。試作の-1.0 m/s²切り替え規則の裏付けは得られず、実車用の条件へ変更していない。

再実行スクリプトと数値結果は同じ調査フォルダ内に保存。詳細は leaf_switch_rule_events.json、leaf_switch_rule_metrics.json を参照。
