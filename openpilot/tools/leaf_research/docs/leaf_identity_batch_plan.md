# 識別情報の一括読み出し試験

2026-11-03。単発UDS試験は未実施のまま、一括試験へ置き換える。現時点で実車への追加読み出しなし。

## 一度のREADYで行う内容

|順番|識別番号|意味|
|---|---|---|
|1|F188|メーカーECUソフトウェア番号|
|2|F187|メーカー補給部品番号|
|3|F191|メーカーECUハードウェア番号|

宛先は全て75D/bus0。サービスは22（ReadDataByIdentifier）のみ。意味はローカルopendbcのUDS識別番号定義に基づく。F188は日産FW照会で使われ、F191も共通照会の定義があるが、この車の75Dで各識別番号を読めるかは未知。番号の意味は取得できることの保証ではない。

VINや個体シリアル番号、全識別番号・全アドレス探索は含めない。取得したソフトウェア番号等だけで縦制御の送信元とは確定できない。

## 続行と中止

肯定応答または7F 22 31（要求範囲外）の完了応答なら、通信を0.2秒以上確認して次の固定項目へ進む。サービス拒否、保留、ビジー、条件不一致、セキュリティ拒否、無応答、不完全・不正応答、車両条件や通信の異常では残りを中止する。最初の1件で全体が終了する場合もある。

最大3件の読み出し要求。それぞれ対応する新鮮で正しいISO-TP先頭応答を受けた場合に限り、受信継続のフロー制御を最大1回ずつ、合計最大3回。再送・別バス・別宛先・別サービスへの切替なし。応答上限64バイト、各要求の応答待ち最大0.5秒。専用試験は通常数秒規模で、起動のFW照会・ウォームアップ時間は別。

シーケンス本体と実機送信部の両方で、順番・前要求の完了・間隔・フロー制御条件を確認する。記録不能でも追加読み出しへ進まない。未完了要求と未実施の項目を結果で区別する。

## 変更しない条件

P・速度0・駐車ブレーキの操作員確認・フットブレーキ保持・アクセルOFF・ACC OFF。新鮮な車両状態と診断専用の通信所有、Pandaの通信健全性を確認する。異常時は追加送信しない。

セッション変更・Tester Present・送信停止・リセット・DTC消去・書換え・入出力制御なし。起動全体では通常のFW照会が別に存在する。送信停止候補は無効のまま。

試験はOFFで一度限り予約し、操作員がREADYにする。3項目の間にOFF/READY操作は不要。終了後は通常制御に進まず、操作員がOFFにして警告と記録を確認するまで抑止を保持する。
