# ジャイロの小規模検証

結論は、今回の簡単な補正では0x292との一致が安定して改善しなかったため、ここで深追いを止める。

## 範囲

5cの制動採用区間から、2秒以上続く区間を要求数値の中央値で並べ、20・50・80パーセンタイルに相当する3区間を、結果を見る前に選んだ。各区間は最大8秒。別ルートへの展開、補正パラメーターの最適化、追加走行・機材購入・実車変更は行っていない。

記録版の座標変換に従ってジャイロをdevice座標へ変換し、各区間の開始時の外部姿勢校正を固定して車両前後・左右・上下方向へ射影。最初の40秒内の停止サンプルからジャイロバイアスを中央値推定した。短区間内のピッチ角変化を積分し、加速度の前後・上下成分を区間開始姿勢へ回転した。符号・倍率はデータへの当てはめで選んでいない。既存の100ms中央平均と、以前求めたCANとIMUの70msの時間差を固定した。

これは重力を完全に除去する処理ではない。絶対路面勾配、ロール・ヨーの補正、温度依存のバイアス推定、取付部の振動対策までは実施していない。CAN側がどの座標・姿勢補正を使うかも未確定。

## 比較結果

定常的なゼロ点の違いを除くため、区間ごとの平均を差し引いたずれのRMSを比較した。基準は既存DBCの倍率で読んだ0x292であり、独立して校正された正解値ではない。

|区間開始 秒|長さ 秒|採用点数|最大相対ピッチ変化 度|補正前のずれ|補正後のずれ|変化|
|---|---:|---:|---:|---:|---:|---|
|581.656|4.75|86|1.39|0.080|0.097|20.5% 悪化|
|689.159|8.00|151|0.61|0.092|0.078|14.9% 減少|
|805.857|8.00|150|0.71|0.087|0.079|8.6% 減少|

全点を区間内で中心化したまま合成すると、ずれは0.0874→0.0830。ただし、以前の固定された倍率補正モデルを0x292へ適用する比較では0.0739→0.0808となり悪化した。

したがって一つの基準での小さな平均改善だけから、実際の加速度の推定精度が上がったとは評価できない。ピッチによる補正量自体は最大約0.10～0.21m/s²あり、無視できるほど小さくはないが、現在の比較基準に対して有効な補正方法とまでは言えない。

## 解釈と打ち切り判断

ジャイロが無価値、姿勢変化が影響していない、という結論ではない。区間開始姿勢へ戻したIMUと、座標・姿勢補正が未確定のCAN信号を比べているため、補正が正しくても一致が改善するとは限らない。短時間の積分にもバイアス誤差が残る。

依頼どおり検証を3区間に限定し、ここで終了する。さらに精密な姿勢推定へ広げても、1C3の総制動／摩擦専用の区別やCAN指令の受理条件を直接確定するものではなく、現在の主調査の優先度は上げない。

結果数値はleaf_bounded_gyro_check.json、処理はwork/bounded_gyro_check.py、比較波形データはwork/leaf_bounded_gyro_traces.npzに保存。回転の符号は、静止重力を既知角で傾けた数値例3点でも整合を確認した。
