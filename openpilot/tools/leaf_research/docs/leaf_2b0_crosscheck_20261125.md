# 0x2B0符号の2台目交差検査：leaf-gwのV/Tとb[4]統計

2026-11-25。siigna (leaf-gw、純正AEBを保持するインラインゲートウェイ) が0x2B0の修正版レイアウト V = (b[1]>>4)<<8 | (b[2]&0xF)<<4 | (b[1]&0xF) を提案し、StarPilotの下位2ニブルの入れ替えを注記して、生フレームによる2台目交差検査を求めた。先の候補は q = 4 * ((b[2]>>4)*256 + ((~b[0])&0xFF)) + ((b[7]>>2)&3)。route 3715a6a4bb（49セグメント、2026-11-23走行）のICハーネス経由bus 1受信専用0x2B0 293,912フレームを再集計した。実車への接続・送信・制御変更はない。解析スクリプトとJSON出力は本変更と共に保管（[ARTIFACTS.md](../ARTIFACTS.md)の該当項目を参照）。

## 結論

- Vと反転複写 ~((b[2]>>4)<<8 | b[0]) & 0xFFF は293,912フレーム全てで一致（不一致0）。ニブル入れ替え補正自体は両車で確認済み。
- 中立/アイドル値バイト dc 53 a2 は V = 1315（x4コマンド尺度で5260、leaf-gw READMEのアイドル5260に一致）。ParkのREADYアイドルは一定パターン dc 53 a2 8c 1b 00 ?e 03（siignaのUS車のREADYアイドルは dc 53 a2 ac 1b 00 ?e 03 — 値バイトは同一、b[3]のみ相違）。
- "2518"パターン a8 27 d5 ac 5b 00 ?e 09 は8,718回出現、そのVは常に0x257（コマンド2398）、例外なし。siignaはUSのLEAF_IC公開ルートで同一パターンを報告し、0x1C3圧力 > 0のときのみ出現（835中822）、0x1C3欄とチェックサムも一致。摩擦ブレーキ作動マーカーの読み取りを支持する。
- 本ルートのフレーム間ステップ：|dV| 平均0.857、p99 = 2、最大931（最大ステップは2518状態パターンへの入口）。T（下記）は平均0.356、p99 = 2、最大826。
- 本ログでは0x2B0値は制動側のみに動く。手動の軽加速では非活動パターンを維持し、ICCで約41 km/h・約 +0.8 m/s^2では中立に留まる。

## 1. V/Tの定義と一致検査

[check_2b0_v.py](../check_2b0_v.py)と[V検査JSON](../evidence/leaf_2b0_v_check_20261125.json)、[check_2b0_t.py](../check_2b0_t.py)と[T検査JSON](../evidence/leaf_2b0_t_check_20261125.json)、[extract_2b0_frames.py](../extract_2b0_frames.py)と[抽出JSON](../evidence/leaf_2b0_extract_20261125.json)を追加した。

1. V = (b[1]>>4)<<8 | (b[2]&0xF)<<4 | (b[1]&0xF)。Vinv = ~((b[2]>>4)<<8 | b[0]) & 0xFFF。293,912フレーム全てで V == Vinv、不一致0。
2. T = ((b[2]>>4)<<8) | ((~b[0])&0xFF)。先の候補 q = 4*T + ((b[7]>>2)&3) の12ビット核心がT。TとVは上位ニブルを反転するかどうかでのみ異なる。

## 3. フレーム間ステップと上位ニブルの不一致

### 事実

|統計|値|
|---|---|
|Vステップ 293,863件|平均0.857、p99 2、最大931|
|Tステップ 293,863件|平均0.356、p99 2、最大826|
|(~b[0])巻き戻り交差 304件|平均\|dV\| 500.5、平均\|dq\| 46.8|

ICC定速走行中、b[2]上位 8<->9 境界付近（a ~ 0）での繰り返し例。dV = 508..511、dT = 1..4。

```text
fd 62 90 ac 5b 00 5e 03 -> 00 7f 8f ac 5b 00 6e 06: V 1538->2047, T 2306->2303
```

### 解釈

本車のデータでは上位ニブルは非反転として振る舞い、Vの残るステップはまさにそのb[2]上位8<->9境界に集中する。siignaのUSルートが T ~ 0x900 付近を浮遊するかは未確認——2026-11-25に問い合わせ、彼の確認を待つ。ニブル入れ替え補正自体は両車で確認済み。

## 4. b[4] & 0x40 と b[3] & 0x20

### 事実

b[4] & 0x40 vs cruiseState（本ルート）：

|条件|bit set / 全体|
|---|---|
|engaged + 移動中|139,576 / 139,587 (99.99%)|
|engaged + 停止|clear 36,230 / 40,028 (90.5%)|
|cruise unavailable|never set 0 / 29,172|

b[3] & 0x20 は広い活動族（8c->ac）と共に反転し、停止を含むengaged標本では立ち続ける。siignaのUSルート：bit set 58% vs engaged 61%、彼の読み取り「おそらくICC engaged」。

### 解釈

そのUSルートにengaged停止がほとんどなければ、両データセットは「engaged かつ 移動中」と両立する。
